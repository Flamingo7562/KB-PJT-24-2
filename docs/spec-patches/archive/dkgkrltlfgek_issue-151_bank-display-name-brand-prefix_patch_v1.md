# SPEC-151-01: 국민·농협 표시 은행명 브랜드 접두사 정합화

## 추가 사항

`DEC-BANK-CODE-TABLE`의 은행 코드 `004`와 `011`의 사용자 표시 은행명을 은행 선택 화면이
사용하는 브랜드 표기로 정정한다.

| `bankCode` | 변경 전  | 변경 후    |
| ---------- | -------- | ---------- |
| `004`      | 국민은행 | KB국민은행 |
| `011`      | 농협은행 | NH농협은행 |

- 변경 대상은 사용자 표시값뿐이다. `004`와 `011`의 API 값, 요청·응답 계약, 검증 규칙과
  나머지 18개 은행의 코드·표시명은 바꾸지 않는다.
- 두 은행은 은행 선택 화면에 로고와 함께 노출되는 항목이며, 로고의 브랜드 표기와 표시명을
  일치시켜 같은 선택지가 서로 다른 이름으로 읽히지 않게 한다.
- 은행명은 표시값이므로 기존과 같이 API 값으로 허용하지 않는다.

## 완료 조건

- [ ] 은행 선택 화면에서 `004`가 `KB국민은행`, `011`이 `NH농협은행`으로 표시된다.
- [ ] `004`와 `011`을 사용하는 충전·출금 요청의 처리 결과가 변경 전과 같다.
- [ ] 나머지 18개 은행의 `bankCode`와 표시명이 변경되지 않는다.
- [ ] `KB국민은행`, `NH농협은행` 같은 표시명을 `bankCode` 값으로 보낸 요청은
      `400 VALIDATION_ERROR`로 거부된다.
